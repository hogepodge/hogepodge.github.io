About the Lorenz Attractor

This is a visualization of the Lorenz system — three coupled differential equations discovered by meteorologist Edward Lorenz in 1963 while studying weather patterns.

The system is chaotic: tiny changes in starting conditions lead to wildly different outcomes. Yet the trajectory never escapes — it orbits around two "wings" in a pattern that looks like a butterfly.

Try adjusting the parameters below to see how the shape changes. The red wing corresponds to positive x values, the blue wing to negative.
